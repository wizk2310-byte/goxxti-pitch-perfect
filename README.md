# GOXXTI Pitch Perfect

Build a dark, raw, industrial one-page website for GOXXTI, a hard techno DJ/producer. This is a demo/pitch site — make it look like a serious underground techno artist brand, not a generic template.

VISUAL DIRECTION:
- Pure black background, high contrast
- Accent color: acid/toxic green (#C6FF00 or similar) or blood red — pick one and use it sparingly for punch (buttons, highlights, glitch accents)
- Bold, condensed, distorted-feel display typography for headlines (something like Anton, Archivo Black, or a heavy grotesk) — huge type, tight tracking, uppercase
- Subtle glitch/noise texture or scanline effect in background sections, VHS-distortion feel
- No rounded soft corners, no friendly SaaS look — sharp edges, hard contrast, minimal
- Sparse, confident layout — lots of black space, type doing the work

SECTIONS (single page, smooth scroll, sticky minimal nav):
1. HERO — full viewport, "GOXXTI" massive type treatment, tagline "HARD TECHNO PRODUCER & PERFORMER", subtle animated noise/glitch background, scroll cue
2. LATEST TRACK — embedded music player area (mock a SoundCloud/Spotify embed placeholder styled to match the dark theme), track title placeholder
3. UPCOMING SHOWS — list/table of tour dates (date, city, venue, ticket link button) with 3-4 placeholder shows, one marked "SOLD OUT" or "NEXT UP"
4. PRESS / EPK — short bio paragraph placeholder, artist photo placeholder (dark moody portrait style), quick stats row (releases, shows played, founded year), download press kit PDF button
5. MUSIC — grid of release artwork placeholders (Bandcamp/Spotify/Apple Music style tiles) linking out
6. BOOKING — clean contact form (name, email, event details, message) styled dark, plus direct booking email placeholder
7. FOOTER — social icons (Instagram, SoundCloud, Bandcamp), copyright, minimal

Use placeholder text/images throughout (this is a concept pitch, not final content). Make it feel expensive, underground, and intentional — like a site for an artist who's about to blow up, not a hobby project. Fully responsive.
